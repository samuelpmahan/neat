neat

Small repo-local work records, PCR-aware views, and safe agent updates. Plus the review checklist component.

Checklist component

Drop the custom element into any page:

<script src="https://samuelpmahan.github.io/neat/tick-part-checklist.js"></script>
<tick-part-checklist data-checklist='[...]' storage-key="my-review"></tick-part-checklist>

As an ES module (Node or bundler):

import { tickPartChecklistScript } from 'https://samuelpmahan.github.io/neat/dist/review-component.js';

npm package: @samuelpmahan/neat (./checklist subpath).

Checking records inspection only. It never accepts or promotes work.
